# Frontend Foundation Notes

## Design Tokens
- Primary Green: #2E7D32
- Secondary Green: #4CAF50
- Accent Gold: #D4A017
- Background: #F7F8F5
- Text: #1F2937

## Layout
- Use a centered container with generous whitespace.
- Keep section spacing consistent across pages.
- Prefer simple, airy layouts over dense blocks.

## Interaction
- Buttons and links should use clear hover states.
- Animations should feel subtle and purposeful.
- Respect reduced-motion preferences.
