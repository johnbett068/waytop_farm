# Project governance

The WayTop Farm Project Constitution governs architecture, design, implementation and documentation. The frontend is the executable specification of the final application, while backend services will guarantee security and business integrity.

## Milestone completion review

No milestone may be declared complete based only on rendered pages. Before proceeding, the technical lead must audit and record:

- **Architecture:** constitutional alignment, appropriate component reuse and absence of unnecessary duplication.
- **UI/UX:** brand fidelity, hierarchy, spacing, typography, polish and responsive behavior.
- **Accessibility:** keyboard operation, semantics, appropriate ARIA, contrast and visible focus.
- **Performance:** CSS and JavaScript necessity, asset size, duplication and unused components.
- **Documentation:** page specifications, flows, backend contracts, business rules, permissions and future models.
- **Definition of Done:** every applicable item must pass; exceptions must be justified explicitly.

The review must identify outstanding work precisely. The next milestone cannot begin until blocking findings are resolved.
